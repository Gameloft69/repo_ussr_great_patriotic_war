# СССР в Великой Отечественной войне. Итоги и цена победы (1941–1945)

Учебный проект по истории: презентация, текст доклада и интерактивный квиз в едином стиле **советский конструктивизм / архивная эстетика 1920–30-х**.

### 1. Презентация (`Great_Patriotic_War_Results.pptx`)
**12 слайдов** с конструктивистской вёрсткой:
1. Титульный: тема, период, стиль
2. Предварительный период и начало войны (1939–1941): пакт Молотова-Риббентропа, Финляндия, репрессии, план «Барбаросса», катастрофа июня 1941
3. Битва под Москвой (IX 1941 — IV 1942): три этапа, первый провал блицкрига, ГКО, эвакуация
4. Сталинградская битва (VII 1942 — II 1943): приказ № 227, операция «Уран», капитуляция Паулюса, коренной перелом
5. Курская битва и «десять сталинских ударов» 1944: «Цитадель», Прохоровка, «Багратион», Днепр, выход к границе 1941
6. Военный тыл: эвакуация 2500+ заводов, Т-34/Ил-2, ленд-лиз, женщины (800 тыс.), дети, партийное движение
7. Партизанское движение и подполье: 1,1 млн человек, «рельсовая война», «Молодая Гвардия», З. Космодемьянская
8. Освобождение Европы и битва за Берлин (1944–1945): Ясско-Кишинёвская, Варшава, Белград, Будапешт, Висло-Одерская, Берлин, Празская
9. Цена победы: 26,6 млн демографических потерь (8,7 млн военные + 17,9 млн гражданские), 1710 городов, 70 тыс. сёл, 31,8% промпотенциала
10. Итоги войны: геополитический триумф (ООН, атом, лагерь) vs внутренняя трагедия (репрессии, депортации, ГУЛАГ, холодная война)
11. Ключевые даты и цифры — шпаргалка (таблица 13 строк)
12. Заключение: уроки истории и память

### 2. Текст доклада (`Доклад_Великая_Отечественная_Итоги_Цена_Победы.docx`)
- Связный речевой текст для чтения с трибуны
- Полностью дублирует логику и факты презентации
- Метки переключения слайдов: `[СЛАЙД 1]` … `[СЛАЙД 12]`
- Оформлен в Times New Roman, 14 пт, полуторный интервал, красные заголовки

### 3. Интерактивный квиз (`index.html`)
**Готовый к загрузке на GitHub Pages** (один файл, без внешних зависимостей кроме Google Fonts):
- Стартовый экран с названием и кнопкой «Начать проверку знаний»
- 10 вопросов строго по материалу презентации
- Прогресс-бар с анимированной полосой
- Мгновенная проверка: подсветка правильного/неправильного + историческая справка
- Клавиатурное управление (A/B/C/D, Enter)
- **Тасовка вариантов ответов при каждом запуске/рестарте**
- Финальный экран: счёт, процент, **историческое звание** (6 рангов от «Курсант» до «Маршал Победы»)
- Кнопка «Пройти заново»
- Полная адаптивность (мобильные / ПК)
- Вся графика — CSS и inline SVG, никаких внешних картинок

## 🚀 Развёртывание на GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите содержимое папки `repo_ussr_great_patriotic_war/` в корень репозитория
3. Settings → Pages → Source: Deploy from a branch → `main` / `(root)`
4. Сайт будет доступен по адресу `https://<username>.github.io/<repo-name>/`
